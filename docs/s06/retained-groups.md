# Retained-response review groups

This local library accepts only caller-supplied identities, bytes, status, content type and completeness assertions. It fetches nothing and does not inspect checkpoints. `s06-retained-groups-1` uses `s06-local-detector-2` pair decisions, including its complete HTML, decodable, HTTP 200 and available main-content gates before even identical bytes can become a candidate. SKU variants and insufficient text retain the detector's distinct outcomes. Error-template candidates are not classified as penalties; consult the detector's separate soft-404 result. Scores and hashes are evidence, not a judgment of intent or indexing.

A batch is rejected before extraction if it exceeds 128 pages, 4 MiB of supplied bytes, or a 256-byte nonempty identity, or contains duplicate identities. The detector independently limits each source and extracted text. Identities are sorted lexically before at most 4096 comparisons; the result counts omitted comparisons, unknown reasons, and non-candidates. At most 4096 candidate edges and 128 group members can be retained. These limits bound output as well as work; no results are silently truncated. Missing evidence and omitted comparisons do not establish dissimilarity or site coverage. Each group is a transitive connected component with its supporting edge indices; it does not assert every member pair is similar. Local serialization is for reproducibility, not a new wire contract.

This slice registers no CLI, persistence, crawler, delivery, capability, or feature gate. It is not production readiness or issue completion. Any future delivery requires a separately agreed contract and compatible receivers before producers; rollback would disable that future producer while preserving compatible readers and stored evidence.
