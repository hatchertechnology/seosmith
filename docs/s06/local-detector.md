# S06 local detector prototype

`src/s06_detector.rs` is a reusable source-only prototype exercised through `tests/s06_detector.rs`; it is intentionally not registered with the library, crawler, rules, or delivery. The caller supplies retained bytes, status, content type, completeness and an explicit comparison peer. Labels, case IDs and rationales are never inputs to the analyzer. `s06-local-detector-1` names these local, provisional semantics, not the S14 contract.

A result is a human-review candidate, no candidate under these narrow patterns, or unknown. SHA-256 identifies source bytes and lowercased extracted main text; bounded excerpts, title, H1, approximate body text outside main, and pair similarity provide evidence. Exact byte equality is independent of the main-text similarity calculation. The comparison is pairwise: no discovery or clustering is implemented. A 0.8 Jaccard threshold on unique alphanumeric main-text tokens is experimental, not calibrated; repeated words and order do not affect it. Explicit SKU markers suppress a near-duplicate candidate to accommodate common product variants, but are not proof of legitimacy and can hide other cases. Exact byte equality still yields a candidate. Shared chrome is excluded from the similarity score. Template fraction is only a text-length approximation, not a DOM template model.

Soft-404 detection requires a 200 plus matching exact English error title and H1 patterns. A real 404/410 is not a soft-404 candidate; other statuses, missing source, non-HTML, decoding errors, incompleteness, size limits and missing main content are unknown. This deliberately misses many errors and cannot assess page purpose or rendered content. No word-count minimum determines value. A negative means only that this heuristic found no candidate, not that a page is useful or safe. Human context and H04/H05 remain necessary; candidates are not penalties or spam determinations.

Parsing is capped at 256 KiB input and 32 KiB extracted text; excerpts contain at most 240 characters. The first `main`, `article`, or role-main element is used; pages without one remain unknown. Static descendant text can include hidden text and scripts; extraction does not execute JavaScript, check visibility, determine intent, or handle all encodings perfectly. The source hash and excerpt do not replace retention of source bytes. The caller must provide truthful completeness and status and retain both sources for comparisons. Corpus response metadata is synthetic; corpus agreement is not an accuracy measurement.

No existing contracts, feature gates or deployment change in this slice. S14 semantics and compatible receiver/storage/read surfaces remain prerequisites to any separately reviewed producer integration. Deploy readers first, then gate any future producer; rollback disables new emission while retaining readers for stored evidence. No production readiness, live crawling, rendering or emission is claimed.

Run `cargo test --locked --test s06_detector` and `python3 -m unittest discover -s tests/s06 -v`.
