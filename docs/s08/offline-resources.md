# Experimental offline resource observations

This local-only module derives observations from caller-supplied decoded bodies, header maps, static HTML and existing page relationships. It makes no requests and is not a crawler, persisted collector, wire contract or delivered report. Derived from PR32 `fe8691acd5590bfb8d8db304f2ef9b9d7c73e58b` (`graph_evidence`); it is independent of PR40's graph module.

`decoded_body_bytes` and the SHA-256 hash describe the supplied body, which must be complete for a full-resource claim. `content-length` is a parsed header observation, potentially describing an encoded representation; it is not measured network transfer. `transfer_bytes` is always unavailable. Header keys must be lowercase and maps cannot preserve duplicate header occurrences. Cache, encoding, type and validator values are retained observations, not proof of behavior. PNG/GIF dimensions and PNG/GIF/JPEG/WebP signatures are limited byte-prefix observations, not image validation; declared MIME and detected signature remain separate.

Duplicate groups compare supplied decoded bytes by hash; equality does not establish interchangeability. Totals group supplied decoded lengths by parsed origin and declared type; `complete` is caller-supplied collection coverage and cannot establish completeness of an individual body. Empty groups provide no independent coverage signal. Dependency propagation follows supplied resource relationships and terminates cycles; a missing target may still have an affected-page edge. It does not establish discovery completeness, browser loading, or that a target was fetched. Duplicate page URLs are resolved by the last supplied page, so callers must reconcile duplicate observations first. Callers must retain their own collection and relationship coverage and source evidence before making negative claims.

HTML references preserve source URL and raw static attributes, bounded to 2,000 occurrences and 2,048 characters per attribute, with `complete=false` on truncation. The retained fixture `fixtures/s08/references.html` is synthetic. The selector covers `img`, `source`, `script[src]`, and `link[href]` only; it omits other references such as video posters, iframes and CSS URLs, and does not retain every HTML attribute. `complete` reports only the stated truncation limits, not discovery or attribute completeness. Link occurrences include raw `rel` tokens, including non-resource links such as canonical declarations; they are not classified as dependencies. Source references are observations, not resolved selections; `srcset`, sizes, dimensions, loading and priority do not establish what a browser selected or rendered. Static observations cannot establish rendered oversizing, LCP, actual transfer, or field performance. No production thresholds or issue-completion claim are implied.
