# Offline link graph evidence

`seosmith::graph_evidence` is an experimental local analysis interface extracted from [PR32](https://github.com/hatchertechnology/seosmith/pull/32) at `fe8691acd5590bfb8d8db304f2ef9b9d7c73e58b`. Supply decoded static HTML to `extract`, then pass the resulting pages to `graph` and `fragment_checks`. `canonical_variant_links` accepts recorded `model::Page` observations. No fetching, persistence, report or wire integration is provided. The status argument is retained from the original extraction API and does not affect graph extraction.

Link occurrences retain source page and ordinal, raw href (up to 2,048 characters), resolved URL, fragment-free URL, fragment, element, context, approximate accessible name and link-level rel followability. Unique inlinks count source pages, including nofollow links. Navigation distance uses only observed followable links between supplied pages; discovery alone does not imply navigation. The seed must exactly match a supplied fragment-free page URL; a seed containing a fragment is treated as missing. A missing seed, incomplete supplied coverage or truncated extraction leaves unobserved reachability unknown. Callers must establish coverage separately: `graph_coverage` checks supplied accounting, it cannot prove a complete crawl. `graph` takes coverage accounting and gates negative reachability on reconciled counts, the actual supplied pages, and complete extraction. Caller-supplied accounting remains an assertion, not independent proof.

`graph_with_evidence` additionally accepts retained per-page evidence. `PageEvidence::page_follow` records page-level directive followability: `Some(false)` blocks every link on that page, `Some(true)` permits normal link-level analysis, and `None` (absent, unsupported or inconclusive evidence) is conservative and cannot establish reachability. A page reachable only through unknown followability is `unknown` rather than `not_observed_reachable`. `sitemap_listed` and `canonical_target` report retained membership and declaration evidence separately from navigation; neither establishes first discovery or navigation distance. `graph` remains the link-level-only variant and evaluates no page-level directives.

Fragment absence requires an observed, untruncated target; encoded fragments and unavailable targets remain unknown. Canonical variant results point back to the source and link ordinal and record observed declarations with their retained source (`declaration_source`, `declaration_version`), not validated canonical truth. Full accessible-name computation is not implemented. Extraction caps links at 2,000 and ID/name elements at 10,000; truncation marks the page incomplete. Unsupported schemes, credential-bearing or invalid URLs and invalid or ineligible base URLs are omitted or ignored and mark extraction incomplete. These boundaries mean this prototype does not complete S05 acceptance.

`graph`, `fragment_checks`, `canonical_variant_links` and `saved_canonical_variant_links` return an error on duplicate page URLs (including duplicate recorded model pages and duplicate declaration pages); callers must reconcile observations before analysis. IDs on any element and names on anchors are fragment targets. A matching target takes precedence over the ASCII-case-insensitive `top` fallback; truncated target evidence cannot establish that fallback.

## Saved local checkpoints

`seosmith --database PATH saved-graph REQUEST_ID` reads a terminal local-only job's existing checkpoints and emits local JSON. Use only an offline, quiesced database snapshot; immutable SQLite bypasses locks and does not provide safe concurrent access. Close all database users before copying or analyzing it. The command refuses a WAL or rollback journal and uses SQLite immutable read-only mode, with no schema migration, database creation, requests, or delivery. It accepts at most 1,000 frontier rows, 64 KiB per evidence envelope, 2 MiB aggregate parsed evidence, 10,000 retained links, a conservative 3 MiB graph-result estimate and 4 MiB final output; a row limit and per-page omissions are reported, while excessive output fails without partial JSON. Legacy schemas, absent jobs and non-local terminal states fail explicitly. Unsupported, absent, duplicate, unbound, unavailable and partial collectors are not promoted to complete observations.

The `completion` field records how the local job ended. Normal finalization records `completed`. Recovery records `interrupted`. Older snapshots that lack a finalization record, and unsupported values, yield `unknown`. Discovery coverage remains unknown even when finalization succeeded and every retained graph is complete. Navigation distance uses only retained followable links; discovery via sitemap or other relationships is not navigation. Fragment results depend on retained target evidence and may be unknown. Graph extraction rejects non-HTTP links and marks extraction incomplete; this does not establish absence of other links. No live scan or standard report is generated.

Output is versioned by `semantics` (`seosmith-saved-graph-2`). Each node keeps its retained graph fields and adds `page_follow` (`followable`, `restricted` or `unknown`), `sitemap_listed` (`listed` or `unknown`), and `canonical_target` (`declared`, `not_declared` or `unknown`). Page-level followability is read only from a page's own retained `effective_indexing` follow directive for the crawler's user agent; missing, unavailable or inconclusive directive evidence stays `unknown` and cannot establish navigation. `sitemap_listed` is retained sitemap membership; absence is left `unknown` because sitemap coverage is not proven, and membership is not proof of first discovery. `canonical_target` is `declared` when a retained page's conclusive canonical evidence names the URL, including a page that names itself. It is `not_declared` only when declaration coverage is observed and complete (no omitted page and no row limit) and every retained page's declaration evidence is conclusive; otherwise it stays `unknown`. An omitted or otherwise unobserved declaration source could have declared a canonical that is invisible here, so omission cannot support a negative beyond the observed scope.

`canonical_variants` reports each retained link occurrence whose target page has a conclusive canonical declaration pointing elsewhere, with `source`, `link_ordinal`, `target`, `declared_canonical`, `declaration_source` and `declaration_version`. A self-canonical declaration (a page naming its own URL) is retained as a declaration and makes that page `canonical_target=declared`, but a self-reference is not a variant link and is never emitted here. The declaration is retained evidence, not proof that it caused a fetch and not validated canonical truth; cross-origin, conflicting, incomplete or unavailable declarations are not promoted. Canonical variant output is counted against the 3 MiB graph-result estimate before serialization.

Rows are streamed and URL copies are capped at 8 KiB; longer URLs are omitted without echoing them. The 2 MiB limit covers parsed evidence, not total process memory: SQLite, one row, graph structures, and bounded omission/output construction use additional memory. Up to 1,000 omission URLs of 8 KiB may be held before the final 4 MiB output check.
