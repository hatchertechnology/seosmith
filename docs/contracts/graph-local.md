# Offline link graph evidence

`seosmith::graph_evidence` is an experimental local analysis interface extracted from [PR32](https://github.com/hatchertechnology/seosmith/pull/32) at `fe8691acd5590bfb8d8db304f2ef9b9d7c73e58b`. Supply decoded static HTML to `extract`, then pass the resulting pages to `graph` and `fragment_checks`. `canonical_variant_links` accepts recorded `model::Page` observations. No fetching, persistence, report or wire integration is provided. The status argument is retained from the original extraction API and does not affect graph extraction.

Link occurrences retain source page and ordinal, raw href (up to 2,048 characters), resolved URL, fragment-free URL, fragment, element, context, approximate accessible name and link-level rel followability. Unique inlinks count source pages, including nofollow links. Navigation distance uses only observed followable links between supplied pages; discovery alone does not imply navigation. The seed must exactly match a supplied fragment-free page URL; a seed containing a fragment is treated as missing. A missing seed, incomplete supplied coverage or truncated extraction leaves unobserved reachability unknown. Callers must establish coverage separately: `graph_coverage` checks supplied accounting, it cannot prove a complete crawl. `graph` takes coverage accounting and gates negative reachability on reconciled counts, the actual supplied pages, and complete extraction. Caller-supplied accounting remains an assertion, not independent proof.

Fragment absence requires an observed, untruncated target; encoded fragments and unavailable targets remain unknown. Canonical variant results point back to the source and link ordinal and record observed declarations, not validated canonical truth. Page-level nofollow and full accessible-name computation are not implemented. Extraction caps links at 2,000 and ID/name elements at 10,000; truncation marks the page incomplete. Unsupported schemes, credential-bearing or invalid URLs and invalid or ineligible base URLs are omitted or ignored and mark extraction incomplete. These boundaries mean this prototype does not complete S05 acceptance.

`graph`, `fragment_checks`, and `canonical_variant_links` return an error on duplicate page URLs (including duplicate recorded model pages); callers must reconcile observations before analysis. IDs on any element and names on anchors are fragment targets. A matching target takes precedence over the ASCII-case-insensitive `top` fallback; truncated target evidence cannot establish that fallback.

## Saved local checkpoints

`seosmith --database PATH saved-graph REQUEST_ID` reads a terminal local-only job's existing checkpoints and emits local JSON. Use only an offline, quiesced database snapshot; immutable SQLite bypasses locks and does not provide safe concurrent access. Close all database users before copying or analyzing it. The command refuses a WAL or rollback journal and uses SQLite immutable read-only mode, with no schema migration, database creation, requests, or delivery. It accepts at most 1,000 frontier rows, 64 KiB per evidence envelope, 2 MiB aggregate parsed evidence, 10,000 retained links, a conservative 3 MiB graph-result estimate and 4 MiB final output; a row limit and per-page omissions are reported, while excessive output fails without partial JSON. Legacy schemas, absent jobs and non-local terminal states fail explicitly. Unsupported, absent, duplicate, unbound, unavailable and partial collectors are not promoted to complete observations.

The saved job state cannot distinguish successful finalization from recovery of an interrupted local job, and retained checkpoints do not establish complete discovery. Coverage therefore remains unknown even when every retained graph is complete. Navigation distance uses only retained followable links; discovery via sitemap or other relationships is not navigation. Fragment results depend on retained target evidence and may be unknown. Graph extraction rejects non-HTTP links and marks extraction incomplete; this does not establish absence of other links. No live scan or standard report is generated.

Rows are streamed and URL copies are capped at 8 KiB; longer URLs are omitted without echoing them. The 2 MiB limit covers parsed evidence, not total process memory: SQLite, one row, graph structures, and bounded omission/output construction use additional memory. Up to 1,000 omission URLs of 8 KiB may be held before the final 4 MiB output check.
