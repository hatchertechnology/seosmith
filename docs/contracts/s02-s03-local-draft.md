# S02/S03 collection draft (local only; not frozen)

`fixtures/s02-s03/local-collection-v1.json` is an illustrative draft, not a wire contract or validated producer output. A new independently versioned wire extension, registry and receiver vectors must be agreed before emission. Existing v1/v2 and local schema 3 stay unchanged. Missing sidecars on old or resumed jobs are unavailable, never empty evidence. Collection interval is the enclosing crawl interval, not a fabricated fetch timestamp.

Occurrences bind to the containing exact page URL or sitemap URL. `ordinal` is zero-based within the same source on that page, in input order, including malformed occurrences. For HTTP, retain each UTF-8 header field occurrence and its HTTP-library iteration position before interpreting agent scopes or directives; a non-UTF-8 relevant field makes HTTP capture unavailable; parsed bot/value alone cannot reconstruct bytes. HTML occurrence retains DOM-decoded attribute values (not original HTML bytes) and whether it appeared in head or body, together with document-order index (DOM reparenting and byte offsets are not claimed). HTTP Link and HTML canonical observations are separate; raw missing, empty, invalid and valid values are distinct. Alternate occurrences retain raw rel, hreflang and href attributes, parsed target or error, and position. Parsing never turns uncollected evidence into an empty successful collection.

Sitemap documents retain their URL, initiating sitemap URL or robots/default discovery source, status, fetch and parse state, and raw entry occurrences in order. Entries retain raw loc and lastmod, explicit missing/empty/invalid/valid states, and resolved scope status. Multiple origins for the same target are independent entries. A valid lastmod needs a defined date grammar; `present` alone does not imply validity. Parse failures and limits make collection incomplete, including when a prefix of entries is available.

Candidate limits: 2,000 occurrences per category per page, 16,384 UTF-8 bytes per raw value, and bounded document/body and sitemap limits inherited from the fetcher. Track every omitted occurrence if count is known, otherwise an explicit unknown omission count; never silently truncate or report complete. Bounds and exact representations remain subject to cross-owner review. Total storage and collection budgets must be specified before implementation is enabled. Capture mode must be durable from submission through recovery; sidecar and page checkpoint must commit atomically. Local collection is not an authorization for incompatible delivery.
