# Experimental structured-data validation

The `structured_validation` library module is local-only. `seosmith validate-structured REPORT.json` validates an existing saved crawl report without submitting a job or writing to the delivery queue. It produces a standalone wrapper with validation observations and rejects other experimental contract modes. Live crawl integration awaits a durable local-only job mode. It does not alter schema 1/2/3 receipts. Its profile `google-subset-2026-11-21.1` is a deliberately incomplete set of checks, not a comprehensive vocabulary or provider validator. Observations carry a category, code, retained value where available, and an RFC 6901 pointer relative to the page's `structured_data` array; missing-property pointers describe the expected location. The caller must retain the original page and block as provenance.

The subset recognizes Product, Article/NewsArticle/BlogPosting, BreadcrumbList and LocalBusiness, and some text value shapes, missing fields, and local JSON-LD references. JSON syntax errors come from existing extraction. It accepts extracted microdata shape, but does not perform JSON-LD expansion, context resolution, subclass inference, or full schema.org validation. Remote contexts and referenced resources are never fetched by this module. The separate resource lookup reports only status already present in crawl observations; absence and blocked/error observations remain unknown. Rendered content and business facts are unavailable: visible-content alignment always requires human review. A headline differing from retained source headings is only a review candidate, not evidence that it is invisible. A clean result does not establish eligibility or guarantee a rich result. Truncation is explicitly reported; absent evidence on partial extraction must not be treated as conclusive.

Profiles are based on Google's [Product snippet](https://developers.google.com/search/docs/appearance/structured-data/product-snippet), [Article](https://developers.google.com/search/docs/appearance/structured-data/article), [Breadcrumb](https://developers.google.com/search/docs/appearance/structured-data/breadcrumb), and [Local Business](https://developers.google.com/search/docs/appearance/structured-data/local-business) documentation, reviewed 2026-11-21. This is a selected subset and profile changes require versioning and review.

## Release boundary

S14's cross-repository wire format remains under review. Before any integration or emission, agree on versioned records, bounded evidence, source locators and registry semantics with HTP; add paired positive and negative receiver/producer fixtures, deploy receiver and truthful H04 display first, and verify exact receipt compatibility. Gate emission off by default until that work and real-host verification complete. Roll back by disabling emission and retaining legacy readers and immutable reports. This module alone does not complete issue #4: complete type and nested-property checks, local reference semantics, referenced-resource integration, visible-content mismatch candidates, coverage policy, end-to-end tests, and production verification remain.
