# Local S14 contract review bundle

Run `node scripts/test-s14.mjs` from the repository root. `scripts/check-s14.mjs PATH` independently parses and checks one report without invoking Rust or regenerating the candidate. The runner checks seven positive producer reports (complete, partial, omitted, explicit intent, resolved, blocked target and reordered links), six full-policy byte/digest vectors, scope/manifest identity vectors, lifecycle decisions and committed negative mutations. The ignored Rust `export_candidate_fixture` test regenerates report fixtures; it is not needed to run the JavaScript checker.

The full-policy vector `volatile_ids_unchanged` supplies different run, website, binding and timing inputs while keeping policy bytes equal. Website and binding still affect the separate scope digest and must be authenticated independently. Manifest digest excludes run-specific populations, which the validator separately verifies. Edge ordinals are report-local and cannot resolve across runs. The test bundle and exact encodings remain proposed pending independent review; neither local acceptance nor H01's schema-3 rejection demonstrates receiver support or H04 readiness.
